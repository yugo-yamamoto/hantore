# 한토레 — 韓国語 単語＆活用トレーニング

Duolingo 風 UI の韓国語単語練習アプリ（HTML/CSS/JS のみ、ビルド不要）。
基本語彙 約1,280語（名詞 790／動詞 232／形容詞 128／副詞・代名詞など 130）を収録し、
YouTube の字幕からも問題を作れる。

## 起動

```bash
uv run server.py                # 静的配信 + 字幕取得API（初回は依存の解決に少し時間がかかる）
powershell.exe -NoProfile -Command "Start-Process 'http://localhost:8080/index.html'"
```

- 学習アプリ: <http://localhost:8080/index.html>
- 問題作成管理画面: <http://localhost:8080/admin.html>

字幕取得を使わないなら `python3 -m http.server 8080` でも学習アプリは動く（保存済みデッキも読める）。

## コース（メニュー）

「韓 → 日」＝韓国語を見て**日本語で答える**、「日 → 韓」＝日本語を見て**韓国語で答える**。

| コース | 出題 | 答え方 |
| --- | --- | --- |
| 名詞 韓 → 日 | `사람` | 意味を4択（誤答は同カテゴリの名詞） |
| 名詞 日 → 韓 | 「人」 | ハングルを4択 |
| 動詞・形容詞 韓 → 日 | `먹다` | 辞書形の意味を4択 |
| 動詞・形容詞 日 → 韓 | 「食べる」 | 辞書形を4択 |
| 活用 韓 → 日 | `먹었어요` | 「食べる／過去形（해요体）」を4択（意味＋活用形の識別） |
| 活用 日 → 韓 | `먹다` ＋「過去形（해요体）」 | 4択、または音節タイルを並べて作る |
| 副詞・代名詞など 韓 → 日 | `너무` | 意味を4択（副詞・代名詞・感嘆詞・依存名詞） |
| 副詞・代名詞など 日 → 韓 | 「あまりにも」 | ハングルを4択 |
| ミックス | 上の8コースをランダム | — |

活用 韓 → 日 の誤答は「同じ語の別の活用形」と「別の語の同じ活用形」から作る。
`사다`/`살다` のように活用形が同じ綴りになる語（삽니다・살 거예요 など）は、
どちらも正解になってしまうため誤答に使わない。

## 動画から問題を作る（問題作成管理画面）

`admin.html` で YouTube の URL を指定すると、字幕から単語を抽出してレッスンを作れる。

1. URL を貼って **字幕を取得**
   `yt-dlp` で韓国語字幕（手動字幕があれば優先）と YouTube の日本語自動翻訳字幕を取得し、
   ノイズ（`[음악]` など）と自動字幕のローリング重複を除いて正規化する。取得した生字幕は
   `decks/.cache/` に残るので、作り直しのときは再取得しない（YouTube の 429 対策）。
2. **既存辞書の語だけを同定**
   名詞は「語＋助詞」、用言は `js/hangul.js` で生成した14活用形と拡張語尾（반말の `같아`・`-지`・`-게`・
   連体形 `-은/-을`・`-겠어`・`-으면서`・敬語 `-셨어요` など約18,000形）、機能語は見出し形と縮約形
   （`나`→`내가`、`이거`→`이게`）の逆引き索引に完全一致で照合する。形態素解析器は使わない。
   照合順は「機能語の見出し → 名詞（＋助詞）→ 機能語＋助詞 → 14活用形 → 拡張語尾」。
   この順にしないと `별로`（あまり）が「星＋로」に、`그리고`（そして）が `그리다`（描く）に食われる。
3. **採否を決める**
   拡張語尾でしか見つからなかった語や、`사다`/`살다` のように同じ綴りになる語は
   「⚠ 要確認」として既定で出題から外れる。字幕の実例（🔊・`▶ 0:42` で動画の該当位置）を
   見ながらチェックを付け外しする。
4. **問題プレビュー**を確認して **デッキを保存** → `decks/<動画ID>.json`
   プレビューは学習アプリと同じ `js/quiz.js` で生成しているので、見たものがそのまま出題される。
5. 学習アプリのホームに「📺 動画から」としてコースが並ぶ
   名詞 韓→日／日→韓・用言 韓→日／日→韓・活用 韓→日／日→韓・🔊 聞き取り・🎯 ミックス。
   語数が足りないコースはグレーアウトする。

デッキは単語のキー（`ko`）しか持たず、訳・品詞・不規則は常に `js/data.js` を正本として引く。
活用問題は**字幕に実際に出てきた形**を優先して出題する（実測で約8割）。

### この方式の限界

- 出題できるのは辞書（約1,280語）に一致した語だけ。結果は動画の性質で大きく変わる。実測:
  初級会話動画（10分）は **191語・カバー率 73.4%**、アイドルのバラエティ動画（21分）は
  **177語・カバー率 55.7%**。後者が低いのはくだけた話し方と運転などの専門語彙が多いためで、
  辞書外の語の **74%は動画中に1回しか出てこない**（覚える価値が低い語）。
  管理画面は「この動画で練習できる語」を主指標に出し、カバー率が低いときはその理由を表示する。
- 辞書外の語は一覧表示のみで出題しない（よく出る語は `js/data.js` に足せば次の取得から対象になる）。
  辞書を増やした後は、管理画面で既存デッキを「読み込む」→「保存」すると新しい語が反映される。
- 自動字幕は音声認識の誤りを含む。管理画面では「自動字幕」/「手動字幕（高品質）」を明示する。
- 例文の日本語は YouTube の自動翻訳。**問題の正解には使わず**、常に `js/data.js` の訳を使う。
- 活用の逆引きは同形の誤検出があり得る（`-기` は `자기`→`자다` を誘発するため索引から除外済み）。

## 活用形

해요体 / 過去（해요体）/ 합니다体 / 합니다体過去 / 안 否定 / 지 않아요 /
을 거예요 / 으면 / 으세요 / 고 / 아서·어서 / 現在連体形 / 고 싶어요 / 고 있어요

対応する不規則・特殊活用：**ㅂ・ㄷ・ㅅ・ㅎ・르 不規則、ㄹ語幹、ㅡ脱落、하다用言**、
母音縮約（오+아→와、이+어→여、되+어→돼 など）、`맛있다`型の連体形（-는）、
「名詞＋하다」の否定分離（공부 안 해요）。

誤答選択肢は「不規則を無視した形」「母音調和を逆にした形」「으の付け外しを誤った形」
「同じ単語の別の活用形」から生成するため、間違いやすい点がそのまま練習になる。

## 読み上げ

画面に出るハングルの横には必ず 🔊 ボタンが付く（吹き出しの出題語、ハングルの選択肢、
正誤フィードバックの正解、組み立てたタイルの形、復習リスト、活用表の全活用形）。
日本語だけの箇所には付かない。

- ホームの「音声」で ON/OFF・速度（ゆっくり／ふつう／速め）・問題の自動読み上げを設定
- 音声は Web Speech API の `ko-KR`（Windows なら Edge / Chrome の韓国語音声を自動選択）
- 韓国語音声が無い環境では既定音声で発話し、未対応ブラウザでは 🔊 を自動的に隠す

## 公開リポジトリに含まれないもの

- `decks/` … 動画から作ったデッキと取得した字幕のキャッシュ。**字幕は動画制作者の著作物**なので
  リポジトリには入れていない（`.gitignore` で除外）。`uv run server.py` を起動すると空の状態で作られる。
- 自分で動画を指定して `admin.html` からデッキを作ると、`decks/<動画ID>.json` が手元にだけ生成される。

字幕の取得は `yt-dlp` を使った非公式の経路で、**個人の学習用**を前提にしている。
取得したデッキや字幕を再配布しないこと。

## 操作

- `1`〜`4` … 選択肢を選ぶ / `Enter` … チェック・つづける / `Backspace` … タイルを1つ戻す
- 聞き取り問題は音声を聞いて音節タイルを並べる（🔊 は何度でも再生できる）
- 右下の **EVENT LOG** … 操作と正誤の履歴。`COPY` でクリップボードにコピー
- ホームの **活用表を見る** … 全用言の活用一覧（検索可）
- XP・レッスン数・正答率は localStorage に保存
